# For Baebo ❤️

A responsive, single-page apology website. It works on phones, tablets, and laptops.

## Publish it with GitHub Pages (free)

1. Sign in to GitHub and create a **new public repository**, for example `for-baebo`.
2. Upload `index.html` to the repository's root (top level).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. Wait a minute or two. GitHub will show your website address, usually:
   `https://YOUR-USERNAME.github.io/for-baebo/`
7. Open that link on your phone to test it, then send it to her.

## Personalize before publishing

Open `index.html` in any text editor. The page currently calls her **Baebo** and uses a sincere apology that takes responsibility without asking her to forgive you immediately. Read it carefully and change any line that doesn't sound like you.

The page uses Google Fonts when internet access is available; it has fallback fonts if not. No login, tracking, or data collection is used.
